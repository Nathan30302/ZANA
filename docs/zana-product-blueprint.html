ZANA

Product Blueprint · Confidential Working Doc

Beauty marketplace for Zambia

A Yango-style dual-app platform for salons, barbershops, and mobile stylists — with float-based provider monetization and a premium booking experience.

July 2026

01Product positioning

ZANA = Zambia’s beauty booking marketplace for salons, barbershops, and mobile hair/beauty pros.
  • Not a full salon ERP like Fresha (inventory, POS, marketing blasts). Borrow Fresha’s polish and dual apps; keep ZANA simpler and marketplace-first.
  • Mentally: Yango for hair — customer orders a service; pro/salon accepts; maps + ratings + trust.
  • Launch focus: Lusaka first, then Copperbelt / Livingstone.

02How accounts work

Do not make “customer” and “provider” the same messy mode inside one screen.

Piece Role
ZANA (customer app) Book, track, rate, pay tip, save favorites
ZANA Pro (provider app) Go online, accept jobs, manage calendar, buy floats
pro.zana.zm (web) Apply / verify to become a professional

Same phone number can be both — like Yango passenger vs Yango Pro. Customer signup is always free and instant. Becoming a pro is a separate verified path.

ZANA Customer App → Become a Professional → pro.zana.zm Apply → ZANA Team Review → ZANA Pro App → Buy Float → Accept Jobs

In-app path

  1. Customer opens ZANA → Profile → Become a Professional
  2. Opens web application (or in-app WebView) with requirements
  3. ZANA team reviews (docs, photos of work, salon/location proof)
  4. Approved → SMS/WhatsApp: download ZANA Pro → buy first float → go online

03Monetization: Floats

Providers do not pay per-booking commission at first. They buy floats from ZANA.

  • Float = pack of job credits (e.g. Starter 10 · Pro 30 · Elite 100)
  • 1 completed / accepted order consumes 1 credit
  • When credits hit 0 → cannot accept new jobs until top-up
  • Buy floats via MTN MoMo / Airtel Money (must-have); cash agent top-up later
  • Salon/shop accounts can buy team floats shared across staff seats
Always show: Credits left · Expires (optional) · Buy more — never bury this.

Float revenue loop

Float packages → MoMo / Airtel → Credits on account → Accept job (−1) → Credits = 0 → top up

04User types

  1. Customer — book home visit or salon appointment
  2. Independent pro — mobile barber/stylist (comes to client)
  3. Salon / barbershop owner — venue profile, staff, photos, hours
  4. Staff under a shop — receives assigned bookings
  5. ZANA admin — approve pros, manage floats, support, disputes

05MVP features

Booking status chart

Requested → Accepted → On the way / Confirmed → In service → Done → Rate + review

Customer app (ZANA) — ship first

  • Phone OTP signup (Zambian +260)
  • Home: map + list of nearby salons / barbers / mobile pros
  • Categories: Barber · Salon · Nails · Bridal/Events · Mobile
  • Provider profile: photos, services + prices (ZMW), ratings, staff, distance, “At shop” vs “Comes to you”
  • Booking: service → stylist (optional) → time → location (home pin or salon)
  • Live status: Requested → Accepted → On the way / Confirmed → In service → Done
  • Chat/call button (masked number optional later)
  • Rate + photo review after job
  • Favorites + rebook
  • Light offline-friendly screens (spotty data)
  • Become a Professional entry point

Professional signup (web)

  • Type: Independent / Salon / Barbershop
  • NRC or passport, selfie, phone
  • Portfolio photos (before/after)
  • For shops: business name, location pin, shop photos, hours, services menu
  • Optional later: PACRA / business permit (not required for MVP independents)
  • Status: Pending → Needs info → Approved / Rejected

Provider app (ZANA Pro) — ship second

  • Go Online / Offline
  • Incoming job card (service, price, distance, client area — full address after accept)
  • Accept / Decline · Navigate to client
  • Mark Arrived / Start / Complete
  • Calendar for salon appointments
  • Buy float + credit balance
  • Earnings summary
  • Shop owner: staff list, assign jobs

Admin (simple web)

  • Approve / reject pros
  • Float packages + prices
  • View bookings / disputes
  • Seed Lusaka launch providers manually at first

06Premium UI direction

Brand feel: warm, clean, confident — African beauty premium. Not generic purple SaaS. Not dark cyber neon.
  • Strong ZANA wordmark as hero identity
  • Deep charcoal + warm gold / copper accent + soft cream surfaces
  • Expressive brand type + clean UI sans
  • Soft map atmosphere, large photography of real Zambian styles/cuts
  • Big tap targets, short copy, Zambian English tone
  • Motion: map pin settle, booking progress pulse, success moments sparingly
  • One job per screen: Discover → Profile → Book → Track

Customer home

  1. Greeting + location
  2. Search
  3. Category row (few icons)
  4. Map-first nearby results

Pro home

  • Online toggle
  • Credit float meter
  • Next job
  • Nothing else fighting for attention

07Fresha / Yango lessons

Take

  • Dual apps (customer + business)
  • Rich profiles, photos, instant booking feel
  • Ratings trust loop
  • Simple phone signup for customers
  • Separate verified pro onboarding

Skip for MVP

  • Full POS, inventory, payroll, marketing blasts
  • Complex multi-branch enterprise tools
  • Card-only payments (Zambia needs MoMo first)

09Launch sequence

  1. Week 0–2: Brand, wireframes, float packages, service taxonomy
  2. Seed supply offline: Onboard 30–50 Lusaka salons/barbers manually (WhatsApp + visits) before public launch
  3. Ship ZANA customer app with seeded providers (even if Pro app is thin)
  4. Ship pro apply web + ZANA Pro with float purchase
  5. Soft launch Lusaka → App Store / Play Store
  6. Expand categories (nails, bridal) once core booking loop is solid

Customers can always sign up freely. Pros grow via in-app link + field team.

10Trust & safety

  • Verified badge after review
  • Photo of pro/shop on job card
  • Ratings visible; auto-pause low performers
  • Report / block
  • Clear cancellation rules
  • For home visits: share trip/status with a trusted contact (phase 2)

11Success metrics

  • Time-to-book < 60 seconds for returning users
  • Provider accept rate > 70%
  • Float repurchase within 7 days of credits depleting
  • 4.5+ store rating
  • Repeat booking rate (the real moat)

12Immediate next deliverables

  1. Product wiki: roles, float rules, booking states
  2. UI design system + key screens (customer home, provider profile, book, Pro online, buy float, become-pro web)
  3. Scaffold Flutter apps + API + Postgres schema
  4. Lusaka seed data model (Roma, Kabulonga, CBD, Woodlands, etc.)
